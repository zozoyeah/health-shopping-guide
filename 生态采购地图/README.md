# 生态采购地图 MVP - Notion 导入指南

## 文件结构

```
生态采购地图/
├── README.md              # 本文件
├── 首页.md                # 主入口页面
├── 食用油.md              # 食用油品类页
├── 调味品.md              # 调味品品类页
├── 朴门星球.md            # 平台介绍页
└── 我最该换什么.md        # 优先级建议页
```

## 导入 Notion 的两种方法

### 方法一：复制粘贴（推荐）

1. 打开 Notion，创建新页面
2. 依次创建 5 个子页面：
   - 首页
   - 食用油
   - 调味品
   - 朴门星球
   - 我最该换什么
3. 打开每个 .md 文件，复制内容
4. 粘贴到对应的 Notion 页面
5. 手动添加页面间的链接

### 方法二：Notion Import

1. 打开 Notion
2. 点击 `Import` → 选择 `Markdown`
3. 选择整个 `生态采购地图` 文件夹
4. 等待导入完成
5. 手动调整页面链接

## 页面链接说明

导入后需要手动设置内部链接：

- 首页 →食用油、调味品、朴门星球、我最该换什么
- 食用油 → 首页
- 调味品 → 首页
- 朴门星球 → 首页
- 我最该换什么 → 首页、食用油、调味品、朴门星球

## 测试建议

1. 先测试一个入口（比如"按品类找"）
2. 记录用户点击路径
3. 一周后根据数据调整
